Solo Build

preCaution · Grounded, Not Generated

The Build

Built solo for Anthropic's Built with Claude: Life Sciences hackathon, on the Builder Track. preCaution reads a free-text experimental protocol and returns a source-linked safety brief specific to that procedure, instead of an 80-page safety data sheet dump. It needs a language model for one reason: comprehension, accumulation, and omission-detection across messy prose that a database query cannot read.

Grounded, Not Generated

Four stages, and Claude runs in exactly one of them. Stage 1 reads the protocol into structured state. Stages 2 to 4 make zero model calls: live PubChem lookups for grounding, a hand-encoded interaction table from NOAA CAMEO Chemicals, and pure-Python composition of the brief. Claude read the protocol. Claude did not write the safety advice.

Why It Matters

The signature demo is a piranha solution protocol, where sodium azide in a later rinse meets an acidic waste stream from four steps earlier and produces hydrazoic acid. No ingredient-list screener catches this, because it only appears when you track which chemicals share a vessel across the prose. That is the case for a protocol-aware reader routed through deterministic, sourced logic.

AI × AI

Agent vs Agent · A Live AI Debate

The Build

Two AI agents take divergent stances on the same question and debate in real time, with voice output so an audience can follow who is speaking without watching the screen. React and Vite frontend, the Anthropic API for reasoning, built around a three-layer architecture: a fixed identity per agent, a randomly selected stance per run, and full conversation history passed into every call.

The Insight

Temperature alone did not create meaningful divergence. The randomness that actually makes each run diverge lives at the prompt level, in the stance modifier appended to each agent's system prompt. The personas, a sceptical COO and an optimistic Chief AI Officer, were placeholders on top of that mechanic.

The Delivery

Presented to a C-suite, Director, and senior-executive audience at an NTU PACE executive leadership workshop. The demo was the proof point for a larger arc: from building systems, to building the bridge between systems and people, to asking what gets built and why. The work was credible enough that NBS later sought advice on running AI for a faculty-level public panel.
